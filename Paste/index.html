未登录 · 游客模式
工作方式
· 输入框支持任意文本。
· 若检测到 ss://、ssr://、vmess://、vless://、trojan://、hy2:// 等代理节点，将按节点集合处理。
· 订阅模式下（?sub=Auto），后端会根据不同客户端自动转换为对应的订阅格式。
· 文本 / 代码 / 配置等会保持原样，只提供访问和管理链接，不做格式转换。
内容类型识别
输入区域右侧会实时提示内容类型：
· X 条代理节点：表示成功识别为节点列表，此时查看 / 订阅按钮会在用户中心中出现。
· HTML 片段 / JSON 数据 / 配置文本 / Shell 脚本 / JS 代码 / SQL 语句 / 日志：只标记类型，不参与转换。
· 其余则显示为 文本内容。
登录 & 用户中心
登录后可在「用户中心」中查看你创建的所有记录，包括：
· 标题（备注）、短 ID、创建时间、到期时间。
· 快速复制、打开、编辑、删除。
· 当记录被识别为代理节点时，会额外显示一个 订阅 按钮，指向 /api/paste/{slug}?sub=Auto。
